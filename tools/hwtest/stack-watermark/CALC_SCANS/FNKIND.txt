NOP ; Operating time and stack high-water of one case per kind of function, one or two functions each.
NOP ; No nesting: every case runs a single engine at most. Cheapest and safest case first, so where the
NOP ; output stops is itself a result. Needs a build with STACK_WATERMARK set in defines.h; on a build
NOP ; without it the run still completes and STCKST reads the 9 KSET stores, saying so, and only the times are real.
NOP ; The system flag PrintACT is clear unless set, so the print steps write to a dated DATA\*.REGS.TSV.
NOP ; The program never stores STCKSPN. Each machine's own default stands: 8088 on a DM42, 16384 on a DM42n.
NOP ; A case that kills the calculator does not end the test: store the next case number in R94 and XEQ FNKFROM,
NOP ; which runs that case and every one after it. One case alone is XEQ M nn, the wrappers being M01 upward.
NOP ; Raising it is yours to do, before the run, and only on a machine where you know the depth is safe.
NOP ; Five lines per case: the stack figure, its STCKST, STCKSPU, how many calls fitted in the time
NOP ; window, and the tenths of a second that took. STCKST: 0 the figure is a depth reached, 1 the marker
NOP ; ran out so it is a floor, 2 nothing was disturbed, 3 no marker was laid. Only 0 is a measurement.
NOP ; The window is one second a case unless the table says otherwise, so nothing is sized in advance and
NOP ; the same program works on a machine eighty times slower than another. Time per call is the tenths
NOP ; divided by the count. Case 01 is empty, so its figures are the loop and call overhead every other
NOP ; case also pays: subtract it. Integration runs at ACC 1E-3 and the plot, matrix and solve cases at
NOP ; SDIGS 6, since the cost and the depth are under test and not the answer.
NOP ; Uses R95 to R98, R20 to R23, the named variable kvv, the STCK set, the TVM variables and the stat
NOP ; registers. Run it on a state you do not mind touching. Notes in README.txt.
# Jaco Mostert  Function kinds 2026-07-29
